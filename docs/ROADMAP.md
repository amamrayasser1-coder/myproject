# Roadmap
1. Connect Cineva's existing TMDB model without duplicating metadata requests.
2. Add approved provider adapters one at a time with fixture-based parser tests and documented terms/permission review.
3. Add HLS/DASH manifest parsing and validate every variant and segment host.
4. Add encrypted provider configuration and redacted diagnostics.
5. Add persistent Room cache with expiry and migration tests.
6. Add Media3 instrumentation tests for subtitles, headers, buffering and playback errors.
7. Add verified resumable downloads with checksum/size validation.
8. Add privacy-safe provider-health metrics.
9. Test Android 8.0+ and current Android versions.
