# Reference influences
Independent Kotlin implementation; no upstream source files copied.
- CloudStream: extensible provider architecture.
- Movie-Web Providers: provider separation and normalized outputs.
- MediaFusion: multi-source fan-out, caching, health and aggregation.
- ResolveURL: resolver separation and request metadata.
- Torrentio: result aggregation and quality-aware selection.
- CyberFlix Catalog: catalog metadata is separate from playable streams.
- LooNatics 3000: Kodi client/integration reference, not a code dependency.
The reference projects have different licenses. Review exact file/revision licenses and attribution obligations before adapting upstream code.
